# Notas de Estudo

Repositório de notas de estudo criadas a partir de resumos de livros/papers e pesquisa própria.

Cada nota é uma **aula completa** que segue:
- 5 partes (abertura, explicação, exemplos, exercícios, resumo)
- Técnica Feynman como validação
- Rigor com marcadores `[confirmado]`, `[hipótese]`, etc.
- Referências sempre com [F-xx] de FONTES.md

**Fluxo:** Resumo de Livro → Nota de Estudo → Pronta para uso no mestrado

**Organização:** Uma nota por conceito, nomeada em kebab-case descritivo.
- ❌ `notas-paper-vaswani.md` (baseado em fonte)
- ✅ `atencao-multi-cabeca.md` (baseado em conceito)

Veja índice em `../NOTAS-INDEX.md`
