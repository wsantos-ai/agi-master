# Resumos de Livros e Papers

Repositório de resumos didáticos gerados pelo agente **book-summarizer**, organizados por livro/paper (referência [F-xx] em FONTES.md).

Cada resumo segue o padrão:
- Metadados (livro, autor, data, relevância no mestrado)
- Conceitos-chave com marcadores `[confirmado]/[hipótese]`
- Explicação didática com exemplos + contraexemplos
- Perguntas abertas para Mapa da Ignorância
- Proposta de nota de estudo

**Fluxo:** Resumo Bruto → Revisão → Nota de Estudo (em `/notas/`)

Veja índice em `../RESUMOS-INDEX.md`
